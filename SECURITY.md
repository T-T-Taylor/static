# Security Policy

## Reporting a Vulnerability

The Static network is a privacy-focused darknet. We take security vulnerabilities very seriously.

**DO NOT open public GitHub issues for security vulnerabilities.**

To report a vulnerability securely:
1. Encrypt your report with our PGP key (fingerprint: `0x0000000000000000` - TODO: Add key)
2. Email us at: `security@static-network.onion` (TODO: Setup secure email)
3. Include a detailed description of the vulnerability and steps to reproduce.
