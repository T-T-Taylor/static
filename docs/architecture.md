# Static Architecture

## Layers

1. Physical Layer - overlay tunnels or mesh links
2. Transport Layer - constant-rate cover traffic
3. Mix Layer - Sphinx packets, batch/shuffle/forward
4. Storage Layer - encrypted chunks, erasure coding, swap, leases
5. Service Layer - content-addressed retrieval
6. Application Layer - hidden services

See README.md for the full design overview.

Detailed architecture documentation to be written as implementation progresses.
